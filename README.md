# CSwithSR Board

Offline teaching board for CSwithSR live classes: S Pen whiteboard and PDF notes inside the CSwithSR lesson template, a camera window, a topic library for O Level / IGCSE and AS & A Level Computer Science, and class recording.

Install: open the GitHub Pages link in Chrome on the tablet, then menu > Add to Home screen / Install app.
Notes, PDFs and recordings are stored only on the device.
